# UI 提示排查 · 2026-10-21

本页记录当时对五个应用与共享 UI 的文案排查与处理。排查对象包含常驻提示、重复状态、说明段落与装饰文案（不含角色卡、文章与提示词正文）。

## 已修复（Tavern）

- 输入区移除 `Shift + Enter 换行` 与 `/ooc 本行指令…` 常驻提示。token 入口移入输入框右侧并只显示百分比，未读取时隐藏。详情去除估算、约、压缩计数与组成说明，只留标题与用量/容量。
- 编辑消息去除删除后续的重复说明。模型设置移除思考开关旁「已开启」/「已关闭」与 Top K 非零「已设定」。桌面折叠按钮移入主导航。对话统一可见视口，并隐藏移动端对话内底栏。
