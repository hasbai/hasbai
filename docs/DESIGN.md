# 共享视觉与交互

适用于五个应用共用的界面能力。以 `packages/ui` 的 Luma primitives、Bits UI 和 Lucide 为复用入口；业务主题及页面层次由对应应用定义。

## 组件与交互

- 可复用组件先归入共享包，再由应用引用；通知使用共享 Notice，不各建一套错误横幅、表单或弹层。
- 所有交互必须通过 UI/UX 反馈，禁止仅用文字提示状态。加载统一使用顶部进度条，内容等待使用骨架；操作使用控件忙碌、完成图标和禁用状态。保留控件名称、无障碍标签、必要错误原因和恢复操作。
- 表单字段有准确标签，就近显示校验错误。保存中阻止重复提交，明确失败保留输入；未保存离开与结果不明确的处理遵守应用写入契约。
- 正常、加载、空数据、错误、窄屏、深色及键盘路径均可操作；涉及金额的页面同时检查隐藏金额状态。
- 焦点可见，弹层关闭归还触发器焦点；移动弹层保留单一内容滚动区和安全区，短屏操作栏仍可达。打开时不自动唤起搜索软键盘。
- 减少动效偏好停用非必要动画，主题保留独立语义色。无障碍身份和名称准确，状态不只靠颜色表示。财务触控目标至少 48px，酒馆至少 44px；其余按应用既有组件规范。
- 只显示真实数据、可执行功能和实际来源。参考图的示例金额、商户标志、评分、涨跌幅及 AI 置信度不得用于生产占位。

## 动画

共享控件使用短暂的颜色、透明度和按压反馈。
五个应用的页面切换复用 `packages/ui` 的 `pageMotion`。
酒馆消息、命令浮层和执行结果展开有入场动画。
流式正文不逐字重播动画，也不强制滚动阅读位置。
系统减少动态效果偏好会停用这些动画。
