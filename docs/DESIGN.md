# 共享视觉与交互

适用于共享前端界面的各应用，以 `packages/ui` 的 Luma primitives、Bits UI 与 Lucide 为复用入口；业务主题与页面层次由各应用定义。

## 组件与交互

- 删除重复标签、快捷键常驻提示与自我解释文案；数值直接展示，详情按需展开，保留操作名称、必要错误原因、不可逆后果与数据边界。
- 可复用组件先归入 `packages/ui` 再引用；通知共用 Notice，不各建错误横幅、表单或弹层。
- 交互必须提供 UI/UX 反馈：页面加载用顶部进度条，内容等待用骨架，操作使用控件忙碌/完成图标与禁用态；表单字段就近显示校验错误，保存中阻止重复提交并保留明确失败输入。
- 正常、加载、空数据、错误、窄屏、深色及键盘路径均可操作；涉金额页面同时检查隐藏金额态。
- 除酒馆外保持焦点可见；弹层关闭归还触发器焦点，移动弹层保留单一内容滚动区与安全区，短屏操作栏仍可达，打开时不自动唤起搜索软键盘。
- 尊重减少动效偏好（停用非必要动画），主题保留独立语义色，状态不只靠颜色区分。触控目标：财务至少 48px，酒馆至少 44px，其余按应用规范。
- 只显示真实数据、可执行功能与实际来源，严禁使用参考图示例数值或 AI 置信度占位。

## 动画

共享控件使用短暂颜色、透明度与按压反馈；前端页面切换复用 `packages/ui` 的 `pageMotion`。酒馆消息、命令浮层与执行结果展开使用入场动画，流式正文不逐字重播动画也不强制滚动阅读位置；减少动效偏好会停用上述动画。
