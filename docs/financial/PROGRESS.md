- 科目 5 位 ID 编辑、两级分类、交易内创建并选中账户；单笔交易及分录删除、无引用科目删除。
- 共享 Auth0 登录与 `financial.all:all` 门禁；数据库 role/GRANT 与 006/007 迁移配套。
- PWA 公开资源缓存、升级/旧 chunk/离线回退，以及基于生产 CSS 的移动端回归。
