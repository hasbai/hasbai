## 数据与功能边界

不复制参考图的虚构金额、百分比或品牌图标。没有数据接口的环比不伪造；AI 建议改为可追溯的历史科目建议。

预算、删除和额外管理功能受现有三表、单人使用及原始记录保留约束，不加入虚假入口。现金流默认所选月份，保留已录入未来交易的30天范围。2026-09-15 首页改为只展示统计，余额/现金/损益面板提供逐日下钻；隐藏金额时同时隐藏图表及每日表格。

## 2026-09-20 内置浏览器移动端美观复查

本轮使用 Codex 内置浏览器，390×844 手机视口直接浏览线上个人账本。检查总览、资产/负债筛选、现金流所选月份/未来空态、损益及逐日下钻。另查流水与筛选弹层/嵌套科目选择、已有支出/新增收入扣款/划转。范围还包括交易操作/退款/完整分录、设置、科目两级展开/编辑/类型弹层/空搜索。仅操作浏览和未保存表单，未保存、退款或删除生产记录。个人数据和线上截图不提交公共仓库。

美观修复方案：

1. 移动端新增圆形加号放入底栏右侧独立位置，导航保留三个入口。图表、科目金额和流水不再被悬浮按钮盖住；同步缩短页面底部空白。
2. 手机卡片统一20px圆角和轻阴影；净资产主卡使用轻微资产蓝底色，金额显隐靠右，主数字与曲线保持层次。
3. 报表月份行上下间距收紧；现金流的查看流水入口与净流入标签同排。期间选择采用浅底选中态，减少深色按钮竞争。
4. 应用/交易操作菜单统一紧凑间距、右对齐和屏幕边缘留白；科目选择搜索框左右内缩16px，与选项对齐；表单弹层输入圆角统一14px。

自动化沿用现有正常、加载、空、错误、隐藏金额、深色、短屏及键盘场景；增加移动底栏新增按钮和三项导航不重叠的行为断言，并登记覆盖清单。所有自动化交由GitHub Actions，本地仅格式化和git diff --check。候选、普通CI及部署结论在交付结果中单独列出。


候选复核：第一轮CI全部通过，但实际截图显示低比例OKLCH混色产生偏粉底色，且窄屏净资产曲线穿过金额末位。改为OKLab混色，并在主卡底部为趋势单独留出44px区域，金额与曲线互不重叠；重新生成对应新提交的候选，不接受首轮截图。
