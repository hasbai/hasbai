2026-09-13 更新。以用户后续明确要求为准：单人个人财务系统，保持简单。原先多账本、成员、独立草稿、审计和额外 schema 的规划已撤销。

## 范围

1. Auth0 北极小站登录，使用 Auth0 superadmin 角色授权；人民币。
2. 总览：资产负债、现金流、损益、趋势和待补录提示。
3. 流水：手机卡片、搜索/筛选/分页、手工新增、补录、科目匹配和分录拆分。
4. 科目设置：新增、编辑原有字段；现金范围直接按既有子类识别。
5. Svelte 5 SPA 静态部署 Cloudflare Worker financial，域名 financial.hasbai.xyz，GitHub hasbai/financial。

## 实现原则

保持现有三张表和全部原字段不变。视图直接计算完整性、三表报表和现金流；保存函数一次提交交易及分录。前端防止连续点击，已有记录复用 updated_at 处理编辑冲突，不加 version。

退款在同笔交易内追加反向分录。历史完整成功/退款记录依原分录计入已记录范围报表，不批量改写来源状态，不猜测合并。现金范围为“资产 / 现金及等价物”。
