# 界面与交互

以用户提供的三张手机 UI 图为基准，使用 Svelte 5、Bits UI、shadcn-svelte、Tailwind CSS 4 和 Lucide。浅蓝灰背景、白色圆角卡片、深石板色主按钮；资产蓝、现金流入绿、流出玫红、损益橙。中文系统字体，金额等宽数字；深色模式有独立语义色。

## 文案约束

禁止解释性小字、常驻说明横幅、口径免责声明、操作教学和技术说明。这些说明也不得放入 tooltip、折叠区或弹窗。首页禁止“XX 笔交易待补录。以下仅反映完整交易的已记录范围，请核对期初覆盖情况。”及同类文案，待补录由带计数入口承载。

本节是财务文案约束的维护入口。日期、金额、图例、科目、字段标签及简短操作状态属于业务信息。口径仅写入[DOMAIN](DOMAIN.md)，界面使用选中筛选、状态、计数、字段校验、空状态操作和明细入口。

## 总览

- 标题为“个人财务”；搜索进入流水，铃铛的待补录入口有状态圆点与可访问计数。
- 总览 / 资产负债 / 现金流量 / 损益切换。总览仅保留净资产主卡、资产/负债双卡、通栏现金流、横排损益；科目余额和损益趋势进入各自面板；总资产/总负债进入资产负债标签，分别选中资产/负债筛选。筛选与报表月份写入URL，支持直接打开与返回。
- 净资产主卡提供金额显隐按钮及基于 SQL 截止时点余额的曲线；不伪造单调增长曲线或涨跌幅。
- 首页只展示统计；现金流、损益在各自面板提供可键盘访问的日期链接，下钻至当天流水。

资产负债面板提供全部 / 资产 / 负债筛选和对应汇总、科目余额。移除每日余额详情列表；净资产趋势继续保留。

## 现金流

默认展示所选月份净流入，保留未来30天切换；流入/流出按日展示柱状图，现金面板展示每日金额，点击日期进入同范围流水。手机为上下布局，桌面为左右布局，整张卡通栏。图例、金额轴、日期和明细表保留，所有说明段落移除。

未来区间为页面打开时点起连续30天。逐笔净额读取现有 cashflow 视图。前端以 Decimal 计算合计、按北京时间日分组并绘图。隐藏金额时不渲染图形或金额明细；无数据、缺现金账户和错误分别给出空状态/设置入口/重试操作。

## 流水

月度收支汇总、月份选择、胶囊搜索框、全部/支出/收入/待补录/待匹配筛选和按日卡片。月度汇总独立标明月份，列表保留已有 URL 筛选和游标分页；选择月份会同步列表起止日期。已入账、现金和日期过滤通过可操作筛选项呈现。

卡片显示真实科目类别图标、商户、时间、带符号金额与分类/缺失状态。支出为负号，收入/退款为正号，转账保持中性。金额未知保留待补录，不能当作零。汇总迷你图来自 SQL 损益逐日数据。

日期输入以北京时间显示，结束日期控件包含所选日，提交时转为 SQL 半开区间；不再用说明括号解释日期边界。

## 修改交易

手机独立路由页面，不使用 Dialog；桌面居中 Dialog。顶部返回、当前交易名称与操作菜单；未填写名称时使用“未命名交易”或“新增交易”。不再重复展示原交易摘要卡。

简单交易直接编辑支出、收入或划转、分类、账户、金额、对方、时间、备注、状态、渠道和流水号。状态、渠道和流水号与其他字段使用同一紧凑列表，不折叠在“交易来源”之后。金额输入同步借贷，类型变更维护相反方向，始终保留原分录 ID。缺分类/账户显示暖色选择控件。分类与账户按 ID 升序选择，不提供未接入的科目建议。

划转、退款、多分录、原有不平衡记录继续进入完整分录编辑。简单业务分录保留单层外卡，分类、金额和账户细项直接列出，不再逐笔嵌套卡片。分录明细、补记退款和保存并下一笔从操作菜单进入。底部为“取消 / 保存修改”，新增为“保存交易”，保存成功返回流水列表；已有交易的操作菜单提供删除，确认后删除交易及全部分录并返回列表。编辑时展示金额，退出后沿用全局显隐。

失败保留输入；重复保存保护、updated_at 冲突、返回/刷新未保存保护保持。网络结果不明确时禁用保存，提供核对流水入口。退款继续加入同一 transaction，原分录保留。

## 应用外壳与科目

移动底栏为总览 / 流水 / 设置，右下角圆形按钮仅显示加号，科目页用于“新增科目”，其他页面用于“记一笔”；桌面侧栏。设置页通过“科目”入口进入科目设置，科目页提供返回设置。手机交易编辑时隐藏应用菜单与底栏，正文独立滚动，顶部返回和底部保存保持可见。金额显隐、外观和退出进入应用菜单，避免顶端重复标题和多排工具。

科目页使用大类、子类两级展开折叠，末层展示科目名称和五位 ID；搜索自动展开匹配路径。新增和修改可输入 ID，校验大类及已有子类编码。无顶部重复新增按钮。修改弹层提供删除入口，已被交易引用的科目禁止删除。以科目标签表示现金范围。

不为参考图中的预算、批量删除、未接入通知、示例涨跌幅及 AI 置信度生成占位控件。遵循既有单人三表和历史记录保留边界。

## 可访问性与验证

按钮/字段至少48px触控，焦点环、明确的控件名称、Bits UI 焦点归还与键盘选择；固定底栏和弹窗操作区保留安全区。金额隐藏连同图形和表格隐藏；减少动效由主题处理。

使用 Playwright WebKit/iPhone 优先的截图比较、触控命中、焦点和状态回归。页面改动提交前在固定 Linux 镜像生成并审阅受影响截图，完整回归在 PR CI 严格比较；流程以[共享 TESTING](../TESTING.md)为准，设备模拟不等同真机。

## iOS 与多分录录入

手机交易编辑使用独立页面，加载与错误也在同一页面容器呈现；科目选择使用底部弹层。正文和选择列表各自只有一个滚动区，科目选择背景由 Bits UI 锁定。

上下左右安全区、VisualViewport 键盘高度与焦点恢复统一处理；保留双指缩放。通用弹窗限高并允许内部滚动，页面横向溢出裁剪且卡片内容可换行。源码与 DOM 验证不等于 iPhone 真机验收。

分类按当前收支类型过滤，收入不生成资产、负债、净资产、支出标题或候选。第一层为 subtype，第二层为具体 name；账户第一层按 type/subtype 区分，第二层为具体账户。已选项重开定位所在大类，搜索在允许范围内跨大类找项目，取消不改值，关闭归还焦点。继续使用同一组件处理完整分录科目选择。

收支表单提供支出/收入/划转切换；简单交易同步金额。分类可拆分，账户可多选多条，收入直接添加扣款。单个到账/付款/转入账户在主动修改来源金额后分配余款，多账户显示待分配差额；差额未平禁用保存，非法金额字段内报错。多分录时禁用类型转换，移除额外行后可切换，避免隐式丢失分录。

可识别的工资扣税、多分类、多账户与划转在重新打开时恢复业务表单；退款、反向科目、不平衡及其他无法无损归类的历史记录使用完整分录编辑。所有编辑继续保留 entry ID 和 updated_at 冲突检测。金额在编辑页显示；全局隐藏偏好不被改写。

## 手机弹层与字号

手机分类、付款/到账/划转账户、完整分录、流水科目筛选共用底部选择面板；类型、状态、渠道与分录方向也从底部选择。退款及科目编辑复用相同弹层容器。容器贴合 VisualViewport 底部，顶部留出安全区，内容内部滚动；桌面仍居中或使用原下拉选择。

弹层向上滑入240ms、向下退出160ms，减少动态效果时跳过位移过程。打开时聚焦弹层，不自动唤起搜索软键盘；点击搜索后才输入。选择/取消归还触发器焦点。搜索输入与选项触控高度至少48px。

手机交易标题18px、其他页面默认标题24px、普通分区标题16px；总额数字24px，“待填写”16px。标题默认样式放在CSS base层，页面字号工具类可以覆盖，避免统一被30px默认值压过。

手机页面、编辑区和所有弹层隐藏滚动条，但保留触摸、惯性与键盘滚动；桌面保留滚动条。桌面居中的translate只在桌面断点生成，手机底部弹层不依赖清除桌面位移。浏览器验收使用实际生产压缩CSS。


## 移动端交互

- 手机流水高级筛选进入底部面板，标题和完成/清空操作固定。选择即时写入既有URL，完成关闭面板；科目、渠道、状态、实际日期等已选条件可见且可逐项清除。桌面保留正文筛选。
- 现金流每日入口在卡片标题，期间切换手机通栏。资产/负债筛选与报表月份同行，窄屏允许换行。
- 损益图按容器宽绘制，保持可读日期和金额轴；收入实线、支出虚线并使用对应语义色，支持负数，不改变金额定义。
- 业务分录添加/拆分放分区标题行，多分录的科目与金额分行。科目编辑固定标题和取消/保存，删除进入标题栏，字段独立滚动。空科目搜索可一键清空。


## 移动端视觉

手机圆形新增按钮恢复右下角悬浮，直径56px，距76px底栏上沿16px；底栏三个入口等分，正文底部保留168px与安全区滚动余量。科目页继续新增科目，其余页面记一笔。手机卡片使用20px圆角、净资产轻蓝底、金额显隐靠右。报表月份行收紧，现金流流水入口与净流入标签同排，期间切换采用浅底选中态。操作菜单保留16px屏幕边距与紧凑行距，选择面板搜索框和列表左右对齐，表单弹层输入使用14px圆角。


### 交易内新增账户

账户选择弹层底部固定“＋ 新增账户”，列表和空搜索均可进入；分类/扣款入口称“新增分类”，完整分录称“新增科目”。在原弹层切换到新增表单，带入当前子类和搜索名称。

沿用科目设置的五位ID、名称、类型、子类、说明字段及校验。付款/到账/转入/转出限资产或负债；收支分类跟随交易类型，扣款限支出，完整分录允许五类。流水筛选不提供新增。

底部操作为“取消 / 保存并选中”。取消、返回或Escape回到原搜索和分组，焦点返回新增入口；成功更新共享账户缓存并选中，回到交易的原账户字段。

交易表单保持挂载，金额、商户、分录与备注不变，不自动提交交易。保存中禁止离开和重复提交；明确失败保留输入，网络结果不确定时禁止重试并提供核对列表入口。字段区独立滚动，短屏保持操作栏可见，不自动唤起键盘。
