# 界面与交互

界面以用户三张手机参考图为基准，使用 Svelte 5、Bits UI、shadcn-svelte、Tailwind CSS 4 与 Lucide。配色采用浅蓝灰底、白色圆角卡片与深石板主按钮。语义色为资产蓝、流入绿、流出玫红与损益橙（深色模式设独立语义色）。字体用中文系统字体，金额用等宽数字。

## 文案约束

不得添加解释性小字、常驻说明横幅、口径免责声明、操作教学与技术说明（包括 tooltip、折叠区与弹窗）。例：不得显示「XX 笔交易待补录。以下仅反映完整交易的已记录范围…」。日期、金额、图例、科目、字段标签与简短操作状态为业务信息。口径只维护在 [DOMAIN](DOMAIN.md)。界面通过筛选、计数、字段校验、空状态操作与明细入口表达信息。

## 页面与视图

- **总览**：标题为「个人财务」。搜索跳转流水。铃铛待补录入口带圆点与计数。页面切换总览、资产负债、现金流量与损益，筛选与月份写入 URL。总览只留净资产主卡、资产与负债双卡（点击跳转筛选）、通栏现金流与横排损益。净资产主卡含显隐开关与基于 SQL 的曲线，不得伪造单调或涨跌幅。资产负债面板提供全部、资产、负债筛选，展示汇总与科目余额（无每日详情列表）。现金流与损益面板提供键盘可达日期链接，下钻当天流水。
- **现金流**：默认显示所选月份净流入，保留「未来 30 天」（页面打开起连续 30 天）切换。流入与流出用按日柱状图，手机上下布局、桌面左右布局。保留图例、金额轴、日期与每日明细（无说明段落）。隐藏金额时，不渲染图形或明细。无数据、缺现金账户与错误分别提供空状态、设置入口或重试按钮。
- **流水**：包含按月标明的月度汇总、月份选择（同步起止日）、胶囊搜索框、URL 筛选与游标分页、损益迷你图。筛选按钮包含全部、支出、收入、待补录与待匹配。按日卡片显示类别图标、商户、时间与带符号金额。支出为负，收入与退款为正，转账中性，缺金额保留待补录。日期控件按北京时间显示，结束日期包含所选日，提交转半开区间（无括号解释）。手机高级筛选放底部面板（即时写 URL，已选条件可以逐项清除）。桌面保留正文筛选。
- **修改交易**：手机使用独立路由，不包 Dialog。桌面使用居中 Dialog。顶部显示返回、交易名与操作菜单（含分录明细、补记退款、保存并下一笔与删除确认）。交易名默认「未命名交易」或「新增交易」。页面不重复原摘要卡。简单交易直接编辑类型、分类、账户、金额、对方、时间、备注、状态、渠道与流水号（同一紧凑列表）。划转、退款、多分录与历史不平衡记录保留业务表单还原或完整分录编辑。编辑保留 `entry` ID 与 `updated_at` 冲突检测，多分录禁用隐式类型切换。拆分与多账户展示待分配差额（未平不得保存）。编辑页固定显示金额，不改写全局显隐。网络结果不明确时，禁用重复提交并提供核对流水入口。
- **外壳与科目**：手机底栏为「总览 / 流水 / 设置」（固定 76px）。右下角为 56px 圆形加号按钮（距底栏 16px，底部留 168px 与安全区余量）。加号在科目页为「新增科目」，其余为「记一笔」。桌面使用侧栏。金额显隐、外观与退出放入应用菜单。科目页按大类与子类两级展开，末层显示名称与 5 位 ID，搜索自动展开。页内用科目标签标示现金范围，不得删除已引用科目。不得为未接入预算、批量删除、通知、涨跌幅或 AI 置信度设占位控件。

## 移动端交互、弹层与可访问性

- **底部选择弹层**：手机分类、账户、完整分录、科目筛选与属性选择器（类型、状态、渠道、方向）共用底部弹层。退款与科目编辑也共用该容器。容器贴合 `VisualViewport`，顶部留安全区，内容独立滚动（桌面居中或用下拉）。弹层滑入 240ms、退出 160ms（减弱动效跳过）。打开时聚焦弹层，不得自动唤起搜索软键盘。取消或关闭归还触发器焦点。收入不生成资产、负债、净资产或支出候选。已选项重开定位所在大类，搜索跨大类匹配。
- **交易内新增账户与分类**：选择弹层底部固定「＋ 新增账户 / 分类 / 科目」。点击在同弹层切入表单，带入子类与搜索名，并沿用 5 位 ID 校验。「取消 / 保存并选中」更新共享缓存并返回原表单，同时保持交易草稿不丢失、不自动提交。
- **字号、滚动与触控**：手机交易标题 18px、默认页标题 24px、普通分区标题 16px、总额 24px、「待填写」16px（放 CSS base 层）。手机隐藏滚动条但保留触摸、惯性与键盘滚动，不得横向溢出。所有按钮与选择项触控高度 ≥ 48px。设备矩阵与截图验收见 [TESTING](TESTING.md) 与 [共享 TESTING](../TESTING.md)。
