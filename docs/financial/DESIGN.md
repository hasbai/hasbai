# 界面与交互

以用户三张手机参考图为基准，使用 Svelte 5、Bits UI、shadcn-svelte、Tailwind CSS 4 与 Lucide：浅蓝灰底、白色圆角卡片、深石板主按钮；资产蓝、流入绿、流出玫红、损益橙（深色模式独立语义色）；中文系统字体，金额等宽数字。

## 文案约束

禁止解释性小字、常驻说明横幅、口径免责声明、操作教学与技术说明（包括 tooltip、折叠区或弹窗，如禁止“XX 笔交易待补录。以下仅反映完整交易的已记录范围…”）。日期、金额、图例、科目、字段标签与简短操作状态为业务信息；口径只维护在 [DOMAIN](DOMAIN.md)，界面通过筛选、计数、字段校验、空状态操作与明细入口表达。

## 页面与视图

- **总览**：标题“个人财务”，搜索跳转流水，铃铛待补录入口带圆点与计数。切换总览 / 资产负债 / 现金流量 / 损益，筛选与月份写入 URL。总览仅留净资产主卡（含显隐开关与基于 SQL 的净资产曲线，不伪造单调或涨跌幅）、资产/负债双卡（点击跳转对应筛选）、通栏现金流与横排损益。资产负债面板提供全部/资产/负债筛选、汇总与科目余额（无每日详情列表）；现金流与损益面板提供可键盘访问的日期链接下钻当天流水。
- **现金流**：默认所选月份净流入，保留“未来 30 天”（当前打开起连续 30 天）切换；流入/流出按日柱状图，手机上下布局、桌面左右布局。保留图例、金额轴、日期与每日明细（无说明段落）；隐藏金额时不渲染图形或明细，无数据/缺现金账户/错误给对应空状态、设置入口或重试。
- **流水**：独立标明月份的月度汇总、月份选择（同步起止日）、胶囊搜索框、全部/支出/收入/待补录/待匹配筛选、URL 筛选与游标分页、损耗迷你图。按日卡片显示真实类别图标、商户、时间、带符号金额（支出负、收入/退款正、转账中性，缺金额保留待补录）。日期控件按北京时间显示（结束日期包含所选日，提交转半开区间，无括号解释）。手机高级筛选放底部面板（即时写 URL，已选条件可逐项清除）；桌面保留正文筛选。
- **修改交易**：手机独立路由（不包 Dialog），桌面居中 Dialog；顶部返回、交易名（默认“未命名交易”/“新增交易”）与操作菜单（含分录明细、补记退款、保存并下一笔、删除确认）；不重复原摘要卡。简单交易直接编辑类型/分类/账户/金额/对方/时间/备注/状态/渠道/流水号（同一紧凑列表）；划转、退款、多分录与历史不平衡记录保留业务表单还原或完整分录编辑（保留 `entry` ID 与 `updated_at` 冲突检测，多分录禁用隐式类型切换）；拆分页/多账户展示待分配差额（未平禁保存）。编辑页固定显示金额但不改写全局显隐；网络结果不明确禁重复提交并提供核对流水入口。
- **外壳与科目**：手机底栏“总览 / 流水 / 设置”（固定 76px），右下角 56px 圆形加号按钮（距底栏 16px，页面底部留 168px + 安全区余量；科目页“新增科目”，其余“记一笔”）；桌面侧栏。金额显隐、外观与退出进入应用菜单。科目页按大类/子类两级展开（末层名称 + 5 位 ID，搜索自动展开，科目标签标示现金范围，禁止删已引用科目）。不为未接入预算、批量删除、通知、涨跌幅或 AI 置信度设占位控件。

## 移动端交互、弹层与可访问性

- **底部选择弹层**：手机分类/账户/完整分录/科目筛选/类型/状态/渠道/方向/退款/科目编辑共用底部弹层（贴合 `VisualViewport`、顶部留安全区、内容独立滚动；桌面居中或下拉）。滑入 240ms / 退出 160ms（减弱动效跳过）；打开聚焦弹层不自动唤起搜索软键盘，取消/关闭归还触发器焦点。收入不生成资产/负债/净资产/支出候选，已选项重开定位所在大类，搜索跨大类匹配。
- **交易内新增账户/分类**：选择弹层底部固定“＋ 新增账户/分类/科目”，同弹层切入带入子类与搜索名，沿用 5 位 ID 校验；“取消 / 保存并选中”更新共享缓存并返回原表单且保持交易草稿不丢失、不自动提交。
- **字号、滚动与触控**：手机交易标题 18px、默认页标题 24px、普通分区标题 16px、总额 24px、“待填写”16px（放 CSS base 层）；手机隐藏滚动条但保留触摸/惯性/键盘滚动，禁用横向溢出；所有按钮与选择项触控高度 ≥ 48px。设备 matrix 与截图验收见 [TESTING](TESTING.md) 与 [共享 TESTING](../TESTING.md)。
