# 报表口径

人民币，Asia/Shanghai。仅基于现有三表，不增加管理字段。

## 完整性

有至少两条正金额分录、科目齐全、借贷平衡才是完整交易。来源状态为 success、refund、partial_refund 的完整交易计入损益及现金流；pending、cancel 不计入。缺分录/缺科目的记录留在待补录队列。零分录不能当作零金额的完整交易。

退款按照现有分录方向冲减支出，不能一概排除。历史记录不自动合并或改状态；旧交易数量仅是[现场/交付基线](history/DELIVERY.md#原始数据保持)，不作为实时规则。

## 资产负债与损益

- 资产余额：累计借方 − 贷方。
- 负债余额：累计贷方 − 借方。
- 净资产：资产 − 负债。
- 期间收入：收入科目贷方 − 借方。
- 期间支出：支出科目借方 − 贷方。
- 净收益：收入 − 支出。

当前资产负债使用用户的 balance 物化视图：只排除同笔包含未匹配科目的分录，不额外筛选状态或完整性。balance_history 同口径计算北京时间每日累计余额，覆盖最早有效交易至维护当天，无交易日承接前日。当前 balance 含全部已录入日期；历史快照只累计到所选日末。

损益使用北京时间期间半开区间。保留有符号余额，不用绝对值修饰报表。历史仅覆盖已记录范围，不能宣称全部资产余额；没有另存期初余额或自动结转机制。

## 现金流自动计算

现金范围为资产类型下的“现金及等价物”子类。每笔完整交易计算现金借方 − 贷方：正值为流入，负值为流出，零值不增加收支。

同笔现金账户之间转账自动抵销。退款在同笔交易中冲减原现金支出。现金流分类先判断收入/支出科目（生活），再判断非现金资产（投资），剩余为筹资；可从流水查看全部分录。

该口径是个人管理用的逐笔净现金流，不额外保存毛流量分配。在相同完整交易集合内，期末现金 − 期初现金 = 同期间净现金流。用户的新 balance 纳入范围更宽，因此不强制其现金余额变化与现金流报表相等。

首页“未来30天”使用从数据快照时点起的30天半开区间。仅汇总已录入的未来日期交易，且须满足上述完整性及成功/退款状态；pending 状态不计入。这是已记录范围汇总，不是历史外推预测。现金流默认所选月份，图表与明细改为北京时间逐日统计，合计与分组均直接读取用户的 `financial.cashflow`，前端用 Decimal 汇总。月度现金流截至所选月末或数据快照时点，以较早者为准。

## 同笔退款

例：消费 100 后退回 30，同一 transaction 下保留“借支出100 / 贷银行100”，追加“借银行30 / 贷支出30”；卡片净支出70、现金净流出70。再次退款继续追加同一交易的分录。

现有模型只有交易头的一个 occurred_at，所以同笔退款随该交易日期归期。若未来需要按不同退款发生日分期展示，另行明确数据模型需求；本轮不添加字段或事件表。

## 验证样例

| 事项 | 净资产变化 | 现金变化 | 净收益 |
| --- | ---: | ---: | ---: |
| 工资 10000 | +10000 | +10000 | +10000 |
| 银行消费100、同笔退款30 | −70 | −70 | −70 |
| 信用卡消费100 | −100 | 0 | −100 |
| 信用卡还款100 | 0 | −100 | 0 |
| 银行转钱包100 | 0 | 0 | 0 |
| 借款到账1000 | 0 | +1000 | 0 |
| 购买投资500 | 0 | −500 | 0 |

以上为虚构测试数据。合计净收益9830、现金净增加10330，已在 SQL 测试中验证。

首页发起读取时由客户端固定 as_of，未来30天、当月损益、现金分组及下钻共用它。余额读取最后一次维护刷新的物化结果。多个源请求不是数据库单语句快照。历史月份读取 balance_history 日终余额及显式期间损益、现金流。首页不显示逐笔交易；现金、余额、损益的逐日统计在对应报表面板，下钻链接带当天日期和对应科目/现金筛选。

## 收入扣款与多账户录入

界面的收入/支出/转账类型及分组仅是现有 entry 数组的编辑投影，不是新增交易字段。工资总额10000、个税500、银行实收9500（虚构验算例）保存为贷收入10000、借支出500、借资产9500；损益收入10000、支出500、净收益9500，现金净流入9500。多账户拆分分别保留各自金额与ID，不能再按两条等额分录归一。

收入的扣款选择支出科目；公积金等资产归属通过资产账户分配或完整分录表达，不默认归为费用。单个目标账户仅在用户主动修改来源金额或移除行时计算差额；读取历史交易不会重写其金额。缺科目仍沿用已有待补录语义，保存金额和借贷平衡校验不放宽。
